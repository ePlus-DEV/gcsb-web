# gcsb-web

Google Cloud Skills Boost helper website for Arcade Points by ePlus.DEV.

## Privacy and analytics

The production site loads Google Analytics by default to measure aggregated usage. A compact cookie information modal is shown to first-time visitors for transparency. The notice can be reopened from the Privacy Policy and does not provide an analytics disable control.

PR previews display the same notice with isolated local storage while keeping the production Google Analytics measurement ID disabled to avoid polluting production analytics.
